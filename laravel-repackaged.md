# Laravel "Repackaged"

I'd like to see many of the different components of Laravel broken up into separate packages that could be re-used in other frameworks or ported to other languages.

Primarily, I'd like to see Laravel's built-in auth system and the Eloquent ORM broken off into separate packages, and ideally ported to JavaScript libraries for use in things like NestJS.

When it comes to Eloquent ORM, there's a project called [Sutando](https://sutando.org/) that is actually working to replicate what Eloquent does in JS, and while it is impressive, there are a few things that aren't quite there for me. In fairness, these things may not be possible, and I can understand that.
