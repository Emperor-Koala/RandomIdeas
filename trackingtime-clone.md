# TrackingTime Clone

[TrackingTime](https://trackingtime.co/) is a time tracking solution that I particularly enjoy using. However, there are a few things about it I'd personally change:
1. They do not have a Linux build. You can still use it on Linux, as they have a web-version and you can use Google Chrome to "install" it as a PWA, but it's not the same as having a true native build of the app.
2. You can only run one timer at a time. Occasionally it would be nice to be able to run multiple timers at the same time dependingon what you're doing or what your workflow entails.
3. There are some thigns I would personally just pare down, based on the way I use it. I would have it such that "tasks" only need to be assigned to "clients" and not to "projects" sice basically how I use it.
